# 短剧剧本生成模板

## 创作条件

- 题材：{{genre}}
- 目标受众：{{audience}}
- 单集时长：{{duration}}
- 角色设定：{{characters}}
- 场景与制作约束：{{constraints}}
- 本集核心冲突：{{conflict}}

## 任务

根据以上条件生成一集适合视频制作的短剧剧本。开场建立冲突，推动人物选择，并在结尾留下悬念。对白应自然，动作与场景应便于视觉呈现。

## 输出格式

1. 标题与一句话梗概
2. 角色和场景清单
3. 分场剧本：场次、地点、时间、动作、对白、预估时长
4. 分镜表：镜头编号、画面、景别、镜头运动、声音、时长
5. 角色一致性要求与所需素材
