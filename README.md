# AI Short Drama Lab

一个探索 AI 生成短剧的实验仓库：从故事创意、剧本和分镜，到画面、配音与视频合成。

## 项目状态

项目初始化阶段。目前提供目录结构、实验记录模板和剧本提示词模板，尚未接入模型或实现生成流水线。

## 计划探索

- 故事创意与单集剧本生成
- 角色设定与跨镜头一致性
- 剧本转分镜及画面提示词
- 图像、视频、配音与字幕生成
- 素材合成、成片评估与成本记录

## 目录

| 路径 | 用途 |
| --- | --- |
| `src/` | 后续生成与合成代码 |
| `prompts/` | 可版本管理的提示词模板 |
| `experiments/` | 实验方案、参数和结果记录 |
| `docs/` | 项目设计与工作流说明 |
| `outputs/` | 本地生成素材与成片，不纳入 Git |

## 开始尝试

1. 复制 `experiments/TEMPLATE.md`，为一次实验建立记录。
2. 填写 `prompts/script.md` 中的创作条件，生成第一版剧本。
3. 记录使用的模型、提示词版本、生成成本与结果，逐步迭代。

后续确定模型供应商与技术栈后，再补充依赖安装和运行方式。API 密钥保存在本地环境变量或 `.env` 文件中。
